# Seller Delivery Delay Prediction

## Problem
Operations teams often react late to delivery delays, leading to poor customer experience.

## Solution
This project uses a simple machine learning model to predict whether an order is likely to be delayed.

## Approach
- Clean and analyze order data
- Train a classification model
- Convert predictions into actionable insights

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Google Colab

## Outcome
Demonstrates how AI models can be translated into practical product features.
